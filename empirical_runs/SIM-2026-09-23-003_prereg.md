# SIM-2026-09-23-003 預註冊:成交額波動折價(Volume-Volatility Discount)

## 1. 假設與經濟機制

Chordia, Subrahmanyam & Anshuman(2001)發現:交易活動**變異度**越高的股票,後續報酬越低(控制交易量水準後仍成立)。
crypto 版本的機制:成交額呈「脈衝式」的幣(日間成交額忽而暴增、忽而萎縮)是**注意力驅動**的標的 ——
每次脈衝對應散戶湧入/社群炒作/上所公告,邊際買家是短期、加槓桿、對價格不敏感的注意力交易者,
在賣空受限與分歧信念下(Miller 1977)價格反映樂觀者估值而被高估,脈衝退潮後回歸;
成交額穩定的幣則由持續、分散的需求定價,錯價較小。因此成交額波動度越高,未來報酬越低。
狀態變數是**成交額的二階動差**,不是報酬的極值(MAX/彩券)、不是成交額水準(規模/流動性)、
不是場所份額、不是主動單失衡,也不是報酬波動(lowvol)—— 後三者之分離由控制變數與必死條款檢驗。

**因子類型:`cross`**(80 幣日線橫截面,`data: universe_1d`,逐幣 `factor(ohlcv_df)`)。

## 2. 規格

- **公式**(`W = 60`):
  `dv_t = close_t × volume_t`(≤ 0 或缺值 → NaN)
  `g_t = log(dv_t) − log(dv_{t−1})`(日間成交額對數變化;差分使訊號對成交額**趨勢**與**水準**皆不敏感)
  **`SIG = g.rolling(W, min_periods=W).std(ddof=1)`**(窗口 t−W+1..t,收盤時已知)
- **宣告方向**:`direction: −1`(成交額波動越高 → 後續報酬越低;Q5 = 最穩定、Q1 = 最脈衝)
- **W 的選擇理由**(看數據前固定):60 日 ≈ 一季,足以涵蓋多次注意力脈衝而非單一事件;
  比 20 日控制變數窗口長,避免與 sig20/max21 同窗機械重疊。只跑 W=60,**不做 W 掃描**。
- **持有期**:`hold = 20`(重疊 JT,權重隨報酬漂移);`entry_lag` 用 pack 預設(universe_1d = 0),延遲 1 期由 R2 檢查。
- **組合**:Q5−Q1(`q=5`),當日合格 < 30 幣不交易。
- **成本**:10 bps/邊。
- **宇宙**:`universe_1d.pkl` 80 幣(日線 2018-07 ~ 2026-07-04);因 `funding: true`,樣本截至 funding 覆蓋末日。
  宇宙為**現存幣倖存宇宙**:脈衝式成交的炒作幣中陣亡者不在樣本內,留下的是存活者 → 偏誤抬高 Q1 報酬,方向**不利於本因子**。
- **Builder 實作要求**:`core/signals/FSIM_Volume_Volatility_Discount.py` 提供 `factor(df, W=60)`,吃單幣 OHLCV df
  (欄位 `timestamp, open, high, low, close, volume`),回傳與 df 等長的 Series;只能用非負 shift,不得出現 `_fwd`;
  最終 `shift(1)`(universe_1d 的 pack 預設 `entry_lag=0`,假設訊號已 shift)。
  〔勘誤 2026-09-23,Stage 0 前、未看任何數字:原文「不得在模組內再 shift(1)」與 pack 語意矛盾,照字面會前視 1 期;Builder 指出後更正。〕

## 3. 複合訊號成分拆解

**非複合訊號**:`SIG` 是單一統計量(對數差分的標準差),非差、比值、份額或勝算比;`components: {}`,R3 不適用。
刻意用對數空間的標準差而非 CV(`std(dv)/mean(dv)`),正是為了避免引入以 `mean(dv)`(≈ ladv 規模)為分母的比值成分。

## 4. 控制變數(pack 內建,Stage 0 判適格性;不預估數字)

| 控制 | 理由 |
|---|---|
| `sig20` | 報酬波動大的日子成交額也大 → 成交額波動與報酬波動機械相關;xs.lowvol 已試 8 次,須證明不是 lowvol 換皮 |
| `max21` | 單日暴漲伴隨成交額暴增;xs.lottery 已封線,須證明不是 MAX 換皮 |
| `ladv20` | 小/不流動幣的成交額天然較雜訊;CSA 的主張正是「控制水準後變異度仍有效」 |
| `mom20` | 近期漲幅引來注意力脈衝;ofi 子線美元層死於 Mom20 重複 |

只對 Stage 0 判為適格者殘差化(v2.4 §4)。

## 5. 現金流腿申報

**P&L 含 funding 現金流腿**(`funding: true`,多方付正費率、空方收)。本因子非 carry 類,但空頭腿實務上走永續合約,
併入 funding 才是可實現的美元層。無 funding 資料之幣該日現金流記 0(pack 行為)。
注意:依機制,脈衝幣的注意力買盤常加槓桿 → 正費率 → 空頭腿**收** funding;此為推測,不作為通過依據。

## 6. 為何美元層可能可收割(回應「排序層真、美元層死」×4)

前 4 次死因:(a) 彩券族 —— alpha 集中在放空不流動彩券幣,套利受限;(b) ofi 子線 —— 美元層是 Mom20 的重複;
(c) 日頻流量訊號換手高、成本吃光。本因子的差別與可證偽點:
1. **慢變數 + 長持有**:60 日滾動標準差逐日只換入/換出 1/60 的觀測,排序高度自相關;hold=20 重疊組合每日只重建 1/20。
   預期換手遠低於日頻流量/MAX21 訊號。由 §7 K4(打平成本 ≥ 2× 假設成本)檢查。
2. **不只靠放空垃圾幣**:機制同時預測「穩定成交的幣」有正超額(非僅脈衝幣下跌)。若 alpha 全在空頭腿,
   即與彩券族同死法。由 §7 K3 檢查。
3. **與 Mom20 / 彩券 / lowvol 分離**:由 §7 K2 檢查。
4. funding 入帳、倖存偏誤方向不利 → 美元層數字偏保守。
以上是可被 §7 殺死的主張,不是保證;先驗仍應偏空(crypto XS 0 validated)。
