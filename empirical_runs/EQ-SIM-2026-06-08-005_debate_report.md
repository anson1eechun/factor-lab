# EQ-SIM-2026-06-08-005 — v2 辯論:小型股 低波 + 動能 + 與 value 組合

**裁決:REJECT(低波/動能/組合)** ｜ value 仍為唯一 edge。

## 背景
延伸 validated value:在小型股池測低波(學界最穩健異象)+動能,並做正交組合(SIM-015 教訓:過 gross-PnL 檢驗)。季頻、25bps。

## 結果(小型股,季頻,143 月)
| 因子 | IC_t | 毛LS | 淨LS | 多頭超額 | 剔5% | OOS |

## 裁決
- **低波 REJECT(反轉)**:小型股**高波**反而贏(2014-26 投機/成長小型股);低波異象主在大/廣 universe。**拒絕翻號**(sign-mining)。
- **動能 REJECT**:12-1 橫截面在此小型股集無 edge(IC_t 0.25)。
- **組合 REJECT**:被低波/動能兩 dud 拖垮(淨 LS −0.52 ≪ value 1.82)。正交性雖佳,但**組合只在成分有正毛利時加分(SIM-015 再現)**。

## 核心發現
1. **value 仍是唯一 edge**;加標準低波/動能只稀釋。
2. **低波/動能也 universe/regime 依賴**:低波在小型股反轉、動能無效——再次印證「異象需放對 universe」。
3. 多因子擴張在現有候選下無效;真正的下一步是找**有正毛利且與 value 正交**的成分(目前未尋得)。
