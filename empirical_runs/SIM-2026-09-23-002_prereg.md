# SIM-2026-09-23-002 預註冊:距 L 日高點的錨定效應(High Proximity)

## 1. 假設與經濟機制

George & Hwang(2004)52 週高點效應的 crypto 版本。交易者以近期高點作為**錨**:價格逼近前高時,
好消息被視為「漲太多/到壓力區」而賣出過早,價格對資訊**反應不足**;遠離前高的幣則相反,
「看起來便宜」的錨定買盤延緩壞消息反映。因此距前高越近的幣,未來報酬越高,直到錨被突破、資訊完全反映。
與 JT 動能的差別:訊號的狀態變數是**相對於路徑最高點**的位置,而非期初到期末的累積報酬;
George–Hwang 在股票上發現前者在控制後者後仍存活、且長期不反轉。本輪要檢驗的正是這一點在 crypto 是否成立。

**因子類型:`cross`**(80 幣日線橫截面,`data: universe_1d`,逐幣 `factor(ohlcv_df)`)。

## 2. 規格

- **公式**(`L = 180`):
  `Hmax_t = high.rolling(L, min_periods=L).max()`(窗口 t−L+1..t,含當日,收盤時已知)
  `ret_L = log(C_t / C_{t−L})`,`runup_L = log(Hmax_t / C_{t−L})`
  **`SIG = ret_L − runup_L = log(C_t / Hmax_t)`**(≤ 0;0 = 位於前高)
- **宣告方向**:`direction: +1`(越接近前高 → 越高的後續報酬)
- **L 的選擇理由**(看數據前固定):crypto 波動約為股票 3–4 倍、資訊週期較短;365 日窗口在 2019-08 起的
  宇宙會使早期可交易日 < `min_n=30` 的比例過高。只跑 L=180 一個規格,**不做 L 掃描**。
- **持有期**:`hold = 5`(重疊 JT,權重隨報酬漂移);`entry_lag` 用 pack 預設(universe_1d = 0),延遲 1 期由 R2 檢查。
- **組合**:Q5−Q1(`q=5`),當日合格 < 30 幣不交易。
- **成本**:10 bps/邊。
- **宇宙**:`universe_1d.pkl` 80 幣(2019-08 ~ 2026-07-04);因 `funding: true`,樣本截至 funding 覆蓋末日。
  宇宙為**現存幣倖存宇宙**:遠離前高且日後反彈者留在樣本內,陣亡者不在 → 偏誤方向**不利於本因子**(抬高 Q1)。
- **Builder 實作要求**:`core/signals/FSIM_Anchor_High_Proximity.py` 提供 `factor(df, L=180)` 與
  `components(L=180) -> {"ret_L": f, "runup_L": f}`(每個 f 吃單幣 OHLCV df);只能用非負 shift,不得出現 `_fwd`。

## 3. 複合訊號成分拆解(v2.4 §5 / v3)

`SIG` 是差分(恆等式 `log(C/Hmax) = ret_L − runup_L`),成分與宣告符號(成分自身 IC 的預期正負):

| 成分 | 定義 | 宣告符號 | 理由 |
|---|---|---|---|
| `ret_L` | `log(C_t/C_{t−L})` | **+1** | 錨定下的反應不足 → 中期報酬延續 |
| `runup_L` | `log(Hmax_t/C_{t−L})` | **−1** | 路徑峰值漲幅 = 長窗 MAX 型彩券特徵;彩券族排序層一貫為負 |

Stage 0:任一成分實測符號相反 ⇒ 敘事不成立;任一成分宣告方向 NW t < 1 ⇒ 組合屬稀釋。兩者皆 KILL。
**已知風險,照實申報**:`runup_L` 與 `ret_L` 正相關,其無條件 IC 可能被 `ret_L` 帶成正號;
若如此即 Stage 0 KILL,不得改拆法補救。

## 4. 控制變數(pack 內建,Stage 0 判適格性;不預估數字)

| 控制 | 理由 |
|---|---|
| `mom20` | George–Hwang 的核心主張就是「不被動能解釋」;也是 ofi 子線美元層的死因(Mom20 重複) |
| `max21` | `runup_L` 與彩券特徵重疊;xs.lottery 已封線,須證明本因子不是 MAX 的換皮 |
| `sig20` | 高波動幣機械地離前高較遠 → `SIG ≈ −vol`;xs.lowvol 已試 8 次,須分離 |
| `ladv20` | 大型/高流動性幣可能系統性地更接近前高(規模效應) |

只對 Stage 0 判為適格者殘差化(v2.4 §4)。

## 5. 現金流腿申報

**P&L 含 funding 現金流腿**(`funding: true`,多方付正費率、空方收)。本因子非 carry 類,但空頭腿實務上走永續合約,
併入 funding 才是可實現的美元層。無 funding 資料之幣該日現金流記 0(pack 行為)。

## 6. 為何美元層可能可收割(回應「排序層真、美元層死」×4)

前 4 次死因:(a) 彩券族 —— alpha 集中在放空不流動的彩券幣,套利受限;(b) ofi 子線 —— 美元層是 Mom20 的重複;
(c) 日頻流量訊號換手高、成本吃光。本因子的差別與可證偽點:
1. **慢變數**:`Hmax` 在 180 日窗內很少變動,`SIG` 排序自相關高 → 換手應遠低於日頻流量/MAX21 訊號。由 §7 K4(打平成本)檢查。
2. **alpha 應在多頭腿**:錨定預測的是「接近前高者續漲」,多頭腿為流動性較佳的強勢幣,不依賴放空垃圾幣。由 §7 K3 檢查。
3. **Mom20 分離**:由 §7 K2 檢查;若美元層被 Mom20 吃掉,即與 ofi 子線同死法。
4. funding 入帳、倖存偏誤方向不利 → 美元層數字偏保守。
以上是可被 §7 殺死的主張,不是保證;先驗仍應偏空。
