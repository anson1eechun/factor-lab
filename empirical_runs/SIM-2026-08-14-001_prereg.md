## 1. 名稱與家族
`FSIM_VenueMigration` — 場所客群遷移(Venue-Clientele Migration)。全新家族。

**鄰接封印面的分離負擔**
- vs **XVENUE_PREM_GAP V1/V2(已 REJECT)**:共用 `universe_1d ∩ coinbase_1d` 資料對,但觀測量不同。XVENUE = 兩所**價格差**(套利摩擦殘量,均值回歸,被套利資本上界綁死);本因子 = **成交量組成比**(客群存量結構,慢變數,無套利機制拉回)。若 Arbiter 認定同通道,Proposer 預先接受計入跨所家族第 3 筆。
- vs **封印 1(funding-level XS carry,7 筆關線)**:訊號**完全不含 funding**;funding 僅作 P&L 現金流腿記帳。依封印條文引用本條。
- vs **封印 2/3(lottery/MAX × 低波動,雙向掛鏈)**:訊號不含 vol、beta、極值報酬或其單調變換。不觸發家族合併計數。
- vs **Amihud 流動性反轉**:Amihud 用流動性**水準**;本因子用兩所**相對份額變化**。

## 2. 經濟假設
加密資產投資人基礎被**監管可及性**切成離岸(Binance)與美國受監管(Coinbase)兩塊。美國 RIA、退休帳戶、合規託管機構與大量美國散戶在法規上無法買離岸掛牌 → 同一枚幣對兩群人不是同一資產。

Merton(1987)投資人認知模型:**可及投資人集合擴張 → 所需風險溢酬下降 → 價格於基礎擴張期間上修**。新客群進場是行政性、分批的(託管商上架、券商白名單、通路排程),買盤在數週內滴入 → **存量重估過程,非一次性跳空**。

- **誰付錢**:離岸既有持有人以逐步上升的價格把籌碼賣給新進場在岸買方。
- **為何不被套利掉**:(a) 遷移速度不可觀測、路徑數週至數季,持有成本(funding、機會成本)實打實;(b) 多頭腿集中中小市值,借券/做空容量與衝擊成本使反向套利不可行;(c) 慢速資訊、不在任何價量動能框內,需跨場所資料拼接才看得到。
- **可觀測代理**:**美國場所佔該幣總成交金額的份額**。份額上升 = 在岸邊際交易者權重上升 = 可及集合擴張。

## 3. 類型
cross-sectional(橫截面多空,dollar-neutral)。

## 4. 精確公式
資料:`universe_1d.pkl`(Binance,**報酬與交易腿來源**)+ `coinbase_1d.pkl`(Coinbase,**僅供訊號**)。交集 69 幣,重疊期 2023-01-01 ~ 2026-07-03(1280 日)。

1. `dv_bn = volume_bn * close_bn`;`dv_cb = volume_cb * close_cb`(USDT/USD 差異 <0.5%,列 disclosure)
2. 兩所日期對齊共同 UTC 日曆(inner join),**缺值不前填**
3. `S_bn = dv_bn.rolling(7).sum()`;`S_cb = dv_cb.rolling(7).sum()`(7 的倍數,消除美國工作日週期)
4. `share = S_cb / (S_cb + S_bn)`,clip 至 [0.001, 0.999]
5. `s = log(share / (1 - share))`(對數勝算,消除 0/1 邊界壓縮)
6. **原始訊號**:`raw[i,t] = s[i,t] - s[i,t-28]`(4 週遷移速度)
7. 樣本過濾(當日):(a) 過去 63 日兩所皆有值日數 ≥ 60;(b) `S_cb ≥ 100,000` USD;(c) 當日通過幣數 `minN ≥ 30`,否則該日不交易
8. 橫截面標準化:當日 `raw` 取 rank → 均勻 → `norm.ppf` 得 rank-z
9. **方向:高分 = 做多**。**符號預先寫死,不接受符號翻轉救援**(對照 IOR-flip 前例)
10. 建倉:每 7 交易日再平衡(以樣本第一個有效日為錨,**固定步長不挑星期幾**),取 z 上/下五分位,腿內等權、兩腿等額(dollar-neutral),持有 7 日
11. 執行滯後:t 日收盤成訊號,**t+1 日收盤建倉**,報酬取 Binance close-to-close
12. 成本:每單位換手 **10 bps**,建倉/平倉兩側各記
13. **現金流腿**:funding 必記(見 §7)

## 5. 參數(唯一主規格)
| 參數 | 主規格 | 先驗理由(非掃描結果) |
|---|---|---|
| 成交量平滑窗 | **7 日** | Coinbase 份額有極強美國工作日週期(週末在岸份額塌陷);7 是消除星期效應的最小值 |
| 變化窗 | **28 日** | 機制尺度為「數週」行政性擴張;28=4×7 同樣消除週期。1 週=追流量噪音;90 天≈退化成份額水準 |
| 再平衡/持有 | **7 / 7 日** | 與訊號尺度匹配;年換手約 40-50x(對照 HollowLeverage 449x 拖 2.2 Sharpe 反例) |
| 分位 | **五分位** | N≈50-60,每腿 10-12 檔 |
| minN / 最小 CB 額 | **30 / $100k** | 資料衛生,非調參 |
| 成本 | **10 bps/單位換手** | book 慣例 |

**Disclosure-only 敏感度(僅回報,永不替補主規格、不得 promote)**:變化窗 14/56 日、持有 14 日、三分位、USD/USDT 匯率校正版、§9 兩個殘差化診斷。

## 6. 預註冊判準(寫死)

**必死條款(命中即 REJECT,不救援、不延長 hold、不中性化搶救)**
- **F1**:平均 RankIC 為負,或 `|IC_t| < 1.0` → 機制證偽
- **F2**:單一日曆季貢獻累積 P&L > **60%**(cap)→ regime artifact
- **F3**:剔除 2024 年(現貨 ETF 年)後毛 Sharpe < **0.2** → 事件特例非通則

**PASS 須全數成立**
| 閘 | 條件 | 型 |
|---|---|---|
| G1 可重現 | 兩次獨立執行主要 metric 差 < 1e-8 | floor |
| G2 排序層 | 平均 RankIC ≥ **+0.02** 且 IC_t ≥ **2.4**(2.0 + 多重比較加嚴) | floor |
| G2c 上限哨兵 | RankIC > **0.15** 不自動 PASS,強制 look-ahead 稽核 | cap |
| G3 美元層 | 淨 Sharpe(含成本+funding)≥ **1.0** 且 非重疊週 t ≥ **2.0** | floor |
| G4 單調 | 五分位 Mono ≥ **0.7** | floor |
| G5 容量 | 剔成交額前 5 大幣後淨 Sharpe ≥ **0.5** 且符號不變 | floor |
| G6 子期間 | 2023-01~2024-12 與 2025-01~2026-07 兩半淨報酬**符號一致**(不要求各自顯著) | floor |

**不確定帶(REWORK)= 非 PASS 且非必死**,明確非空。可實現落點:(a) RankIC 0.03/IC_t 3.2 過 G2 但淨 Sharpe 0.6/t 1.3 敗 G3 → 「排序真、美元不可變現」,與 MAX 同型;(b) 全閘皆過但 G6 符號不一致 → 期間依賴。

## 7. 機制完整性申報
- **現金流腿**:多空皆需以 **perp** 執行(中小幣現貨無可行放空管道)→ **funding 是真實現金流,主規格 P&L 必含**:多頭腿 funding>0 付出、空頭腿收取,逐日以 `funding_1d.pkl`(68/69 覆蓋)計入。訊號本身不含 funding。某幣不在 funding 覆蓋內 → 該日**剔除**(不以 0 填,0 填等於偷正向偏差)。
- `universe_1d` BTC 中位成交額 ~$1.69B/日,量級像**現貨**。須申報「報酬用現貨、現金流用 perp funding」的拼接假設,基差滑移為未計成本(保守方向未知)。
- **上市/退市**:機制最肥的一段(**剛上 Coinbase** 的上架事件)結構性不在樣本內 — 本因子測的是機制**殘量非全量**。
- **倖存偏差**:80 幣全數存活,無陣亡幣。雙向且無法簽署淨方向:(i) 陣亡幣份額崩跌應落空頭腿,缺席使空頭腿獲利**被低估**(保守);(ii) 多頭腿偏中小幣,只有活下來的在樣本內 → 多頭腿**被高估**(灌水)。**若規模中性化後 IC 掉 >60%,Proposer 自行判死**。

## 8. 檢定力粗估
- 有效樣本:過濾後每日 N≈50-60 幣(69 交集中 53 幣有 ≥1000 日),T≈1250 日
- 排序層:單日 RankIC 抽樣 sd ≈ `1/√(N-3)` ≈ 0.137。真實 IC=0.02 → `IC_t ≈ 0.02×√1250/0.137 ≈ 5.2`。**G2 檢定力充足**(可偵測下限 IC≈0.009)
- 美元層(**真正瓶頸**):3.5 年週頻非重疊 → `t = Sharpe × √3.5`。**Sharpe 1.0 僅給 t=1.87 < 2.0** → G3 兩條同時成立實質要求 **Sharpe ≥ 1.07**。「IC 真、P&L 中等」將落 REWORK 而非 PASS
- **若結果為 IC_t 5、Sharpe 0.8,不得解讀為「差一點」而放寬,依規則進 REWORK**

## 10. 證偽路線
