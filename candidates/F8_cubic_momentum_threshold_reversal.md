
**Step 5 — Winsorize（防極端值主導排名）**

$$\text{CMI}_t^{\text{clip}} = \text{clip}\bigl(\text{CMI}_t,\ -3\sigma_N,\ +3\sigma_N\bigr)$$

其中 $\sigma_N = \text{rolling}_N[\text{std}(\text{CMI})]$。

### 前視偏誤防範說明

- `log_ret.iloc[0] = 0`：第一行邊界安全
- EWM `adjust=False`：純遞推計算，無使用未來值
- `rolling(252).quantile()`：視窗完全在 $\leq t$（pandas rolling 預設 `center=False`）
- empiricist 在對齊未來報酬時需額外做 `.shift(-1)`（因子 $t$ → 報酬 $t+1$）

## 質疑 (skeptic)

### DM-1：4 個可調參數 + 滾動分位數 = 高度自適應，過擬合風險被低估
- **類型**：資料探勘
- **具體內容**：候選筆記 Q3 將過擬合風險評為「中等偏高」，但代碼允許 `q_low`、`q_mid`、`q_high`、`halflife` 四個參數自由傳入（代碼第 36-42 行），**並未在代碼層面強制固定搜尋空間**。更嚴重的是，`a_t = rolling_252_quantile(M_t, 5%)`：分位數閾值本身是 M_t 的函數，M_t 又取決於 `halflife` 參數，因此三個「看起來是固定分位數」的根在不同 `halflife` 下會映射到**完全不同的 M_t 值域**，實質上是 4 個連動的自由度。候選筆記聲稱搜尋空間為 3×3×3×3=81（3 個 halflife × 3 個分位數組合近似），但分位數的設定沒有獨立的先驗錨點，是路徑依賴的。
- **嚴重程度**：major
- **建議修正**：(1) 代碼中增加 `assert q_low in (0.05,) and q_mid in (0.75,) and q_high in (0.95,)` 或用 Enum 鎖死「不可自由搜尋」的參數；(2) empiricist 的 walk-forward 必須只允許 `halflife ∈ {7, 14, 21}` 這三個預設值，且**禁止在完整樣本上搜尋後再驗證**。

### DM-2：Smoke Test 值域 [-1e-6, 0] 全為負值，訊號有效性存疑
- **類型**：資料探勘
- **具體內容**：候選筆記第 171 行 smoke test 值域為 `[-1e-6, 0]`，**所有有效值均 ≤ 0**。按照設計，CMI > 0 對應「健康動量（M ∈ (a, b)）」，CMI < 0 對應「過熱（M ∈ (b, c)）」。在 500 根日線樣本中（2024-2025 區間），如果 CMI 全部為負，意味著 M_t 在這段期間**始終處於過熱區**，或是 b_t 的分位數計算有問題導致 `M_t > b_t` 幾乎恆成立。這可能是因為 `rolling(252).quantile(0.75)` 在樣本量不足 252 根時（前 252 天 warmup 期）計算結果偏低，導致 b_t 值失真。
- **嚴重程度**：critical
- **建議修正**：builder 需診斷「為何 500 根中無一筆 CMI > 0」：(1) 列印 M_t、a_t、b_t、c_t 的時序分布；(2) 確認在前 252 日 warmup 期後，M_t 落在 (a_t, b_t) 的比例；(3) 若比例 < 5%，`b_t` 的分位數設置（75%）可能不適合 crypto 的偏態動量分布，需重新校準。

### RW-1：EWM 動量 + 過熱閾值本質上是 RSI/OBV 過熱過濾的連續版本
- **類型**：重複造輪子
- **具體內容**：`M_t = EWM(log_ret, halflife=14)` 是指數加權動量，等價於 MACD（快線-慢線）的連續版本；`CMI = (M-a)(M-b)(M-c)` 的符號邏輯等同「RSI 進入過買區（>75%）時反轉」的三段式過濾，只是用了連續函數而非離散閾值。既有因子庫的 `complexity_gap_regime`（IC-IR = -0.531）已在 regime_switching 類別下捕捉了市場過熱/疲弱的結構轉換；`anchored_mean_reversion_score`（IC-IR = 1.003，value 類別）捕捉了動量均值回歸。F8 的「過熱反轉」假設與這兩者在功能上存在重疊：CMI < 0（過熱）≈ complexity_gap 的羊群衰竭訊號；CMI > 0（健康動量）≈ AMRS 的趨勢延續訊號。
- **嚴重程度**：major
- **建議修正**：empiricist 需計算 F8 分別與 `complexity_gap_regime` 和 `anchored_mean_reversion_score` 的截面 Pearson 相關性；若任一 |ρ| > 0.5，視為功能重疊，需論證 F8 的增量預測力（partial IC，控制既有因子後的殘差 IC）。

### EI-1：雙模式（trend-following + 反轉）自相矛盾，難以形成穩健預期
- **類型**：經濟直覺
- **具體內容**：候選筆記（第 8 行）聲明 `expected_effect: both`（trend-following + 反轉雙模式），訊號規則為：M ∈ (a,b) → long；M ∈ (b,c) → short；M > c → close all；M < a → long。這意味著**同一個因子在不同 M_t 區間的預測方向相反**。從統計回測角度，IC 估計是在所有觀測值上統一計算的，但「M ∈ (a,b)」和「M ∈ (b,c)」的方向相反，若兩個 regime 各佔 50%，整體 IC 可能接近 0（兩段相互抵消），即使每段內部 IC 都顯著。筆記 Q3 承認「M_t 在 (b,c) 區間時做空」，但在 2020/12-2021/4 持續牛市中 M_t 長期 > b，整段做空會持續虧損。
- **嚴重程度**：major
- **建議修正**：empiricist 必須**分段計算 IC**：分別計算「M ∈ (a,b)」子集的 IC-IR 和「M ∈ (b,c)」子集的 IC-IR，而非整體 IC。若兩段方向矛盾，此因子不能以統一信號評估，需拆解為兩個獨立子因子。

### LA-1：滾動分位數視窗內存在概念性前視問題
- **類型**：前視偏誤（邊界案例）
- **具體內容**：代碼第 99-101 行：`a = M.rolling(lookback, min_periods=...).quantile(q_low)`，其中 `lookback=252`。pandas `rolling` 默認 `center=False`，視窗為 `[t-251, t]`，無前視偏誤，這是正確的。**但有一個微妙問題**：`M_t` 本身是通過 `ewm(adjust=False).mean()` 遞推計算的（代碼第 92 行），其 `com` 參數由 `halflife` 決定（第 91 行 `com = 1/(exp(r)-1)`）。EWM `adjust=False` 的遞推初始條件為 `M_0 = log_ret_0 = 0`（代碼第 86 行強制設 0），這個初始條件設置會在時序早期產生系統性偏差：前 ~2×halflife（約 28 日）的 M_t 值受初始條件主導，而非真實動量。若 lookback 視窗前期包含這 28 日的「偏差 M_t 值」，分位數閾值 a/b/c 會被污染。
- **嚴重程度**：minor
- **建議修正**：代碼第 86 行應改為 `log_ret.iloc[0] = np.nan`（而非 0），並在 EWM 計算後將前 `max(28, 2*halflife)` 個觀測值設為 NaN，確保分位數視窗不包含初始條件污染期。
