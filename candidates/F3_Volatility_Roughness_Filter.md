# F3: Volatility_Roughness_Filter — 波動率粗糙度體制過濾器

## 因子類別
波動率體制 / 風險因子 (Volatility Regime / Risk-Based)

## 經濟直覺

傳統計量金融假設波動率遵循均值回歸過程 (如 Heston 模型中的 CIR 過程)。然而，**Gatheral, Jaisson & Rosenbaum (2018)** 的革命性實證發現挑戰了這一假設：**波動率是「粗糙的」** — 其對數波動率的 Hurst 指數 H ≈ 0.1，遠低於 0.5 (布朗運動)，這意味著波動率比傳統模型預測的更「跳躍」且更「反持久」。

**核心經濟直覺**：
- **粗糙波動率 (H < 0.5)**：波動率的變動是反持久的 (anti-persistent) — 今天的波動率飆升意味著明天波動率很可能回落。在粗糙波動率體制下，波動率衝擊快速衰減 → 適合在波動率飆升後進場 (因為波動率會快速均值回歸，期權賣方有利)。
- **平滑波動率 (H ≈ 0.5)**：波動率接近隨機漫步 — 波動率衝擊具有持久性，高波動率區間會持續 → 應降低倉位、收緊止損。
- **極端粗糙 / 非平穩 (H > 0.5 或接近非平穩)**：波動率具有趨勢性，持續擴大或收縮 → 這是危機或極度平靜的信號。

**關鍵行為學機制**：
粗糙度反映了市場的**異質性反應速度**。當市場參與者對資訊的反應速度高度異質時 (有人立即反應，有人延遲反應)，波動率呈現粗糙特徵 — 這是正常市場的標誌。當所有人同步反應時 (如恐慌性拋售)，波動率趨於平滑 — 這是異常市場的標誌。

SuperTrend 已有 Vol≥1.1 的簡單波動率過濾器，但 Volatility_Roughness_Filter 提供了更深層的補充：不僅問「波動率高不高」，而是問「波動率當下的統計特徵是什麼」— 這決定了趨勢信號的可靠性。在粗糙波動率環境中，SuperTrend 的趨勢信號更可靠 (因為波動率衝擊快速衰減，不會破壞趨勢)；在平滑波動率環境中，趨勢信號應打折扣。

## 計算方法草案

```
輸入: OHLCV 資料 (最低要求 1 分鐘或 5 分鐘 K 線)
1. 估計已實現波動率: RV_t = sqrt(sum(r_{t,i}^2))  (每根 K 線內的高頻收益率或使用 Parkinson/GR 估計器)
2. 取對數波動率序列: log_RV_t
3. 使用滑動視窗估計 Hurst 指數 H (多種方法可選):
   a) DFA (Detrended Fluctuation Analysis) — 最穩健
   b) Matern 5/2 kernel GP regression — 與既有 GPR-HS 洞見對齊
   c) 簡單替代: 滯後自相關衰減率
4. 體制判定 (滑動視窗 N=100, 對應約 500 分鐘):
   - H < 0.3: 粗糙波動率 → 波動率衝擊快速衰減 → 進場信號可信度 +1
   - 0.3 ≤ H < 0.45: 中等粗糙 → 正常市場 → 維持標準倉位
   - 0.45 ≤ H < 0.55: 近隨機漫步 → 波動率具持久性 → 倉位降至 70%
   - H ≥ 0.55: 趨勢性波動率 → 異常市場 → 倉位降至 50% 或觀望
5. 輸出: 倉位乘數 multiplier ∈ [0.5, 1.2]，作用於 SuperTrend 或其他基礎策略
```

## 與既有論文洞見的對齊

- **直接對齊**：「GPR-HS 保守波動率 (ANI) 取代 ATR/HistVol 用於 Vol≥1.1 過濾。Matern 5/2 kernel 捕捉粗糙度。」— Volatility_Roughness_Filter 正是將此洞見產品化為可操作的因子
- **跳躍-HMM 互補**：「Jump-HMM 區制相依波動率均值回歸，可融入波動率過濾器」— Hurst 指數可作為 HMM 狀態轉移的觀測變量，粗糙度協助識別區制
- **不對稱設計**：「SuperTrend_asymmetry: α_c=1.8 進/出場比最優」— 粗糙度過濾器可設計不對稱效果：粗糙時進場乘數 > 出場乘數，平滑時反之
- **條件自編碼器**：「條件自編碼器以市場狀態條件化因子生成 (Sharpe 0.94)」— Hurst 指數可作為市場狀態條件之一
- **Permutation test + HPO 穩定性**：粗糙度的滯後參數 N 和 H 閾值需通過穩定性測試
- **Portfolio ES 通過率 100%**：粗糙度過濾器的高 ESG 合規性（純技術指標）

## 論文引用

- **Gatheral, J., Jaisson, T., & Rosenbaum, M. (2018).** "Volatility is Rough." *Quantitative Finance*, 18(6), 933-949. — 革命性論文，實證發現波動率的 Hurst 指數約為 0.1，建立粗糙波動率理論框架。這是本因子的核心理論基礎。
- **Bayer, C., Friz, P., & Gatheral, J. (2016).** "Pricing under Rough Volatility." *Quantitative Finance*, 16(6), 887-904. — 將粗糙波動率應用於期權定價，展示 Matern kernel 的實用性。
- **Bennedsen, M., Lunde, A., & Pakkanen, M. S. (2022).** "Decoupling the Short- and Long-Term Behavior of Stochastic Volatility." *Journal of Financial Econometrics*, 20(5), 961-1006. — 分離波動率的短期粗糙度與長期平穩性，為多尺度粗糙度估計提供方法。
- **Di Matteo, T., Aste, T., & Dacorogna, M. M. (2005).** "Long-term Memories of Developed and Emerging Markets: Using the Scaling Analysis to Characterize their Stage of Development." *Journal of Banking & Finance*, 29(4), 827-851. — 使用 Hurst 指數區分不同發展階段的市場，實證支持 H 作為市場成熟度/穩定性的度量。
- **Cont, R. (2001).** "Empirical Properties of Asset Returns: Stylized Facts and Statistical Issues." *Quantitative Finance*, 1(2), 223-236. — 總結波動率叢聚 (volatility clustering) 等 stylized facts，為粗糙度提供了行為學解釋基礎。

## 預期特徵

- **IC 預期**：0.01–0.03 (作為過濾器/乘數，本身不直接預測方向)
- **Sharpe 貢獻**：預期提升組合 Sharpe 0.2–0.5 (核心貢獻來自降低 tail risk 和避免不利體制)
- **與 SuperTrend 相關性**：預期 ρ < 0.15
- **信號更新頻率**：每 30–60 分鐘 (Hurst 估計需要足夠觀測值)
- **最大 Drawdown 改善**：預期降低 MDD 15-30%

## 風險與限制

1. **Hurst 估計的統計不確定性**：Hurst 指數對估計方法和視窗長度高度敏感。DFA 方法較穩健但計算成本較高。建議使用多種方法交叉驗證。
2. **體制轉換延遲**：Hurst 指數基於滑動視窗，本質上存在滯後。快速度制轉換時可能無法及時調整。
3. **OHLCV 限制**：若僅有 OHLCV 資料，已實現波動率估計精度受限。建議使用 Parkinson (High-Low) 或 Garman-Klass 估計器作為替代。
4. **參數敏感性**：N (視窗長度) 和 H 閾值的選擇需要通過 HPO 穩定性分析和 walk-forward validation。

## 質疑（五維批判）

### 1. 資料探勘風險

- **Hurst 閾值完全任意**：體制分類邊界 `[0.30, 0.45, 0.55]` 沒有任何文獻或實證校正。Gatheral (2018) 發現對數波動率的 H ≈ 0.1，若此結論在 crypto 5-min 資料上也成立，則大多數觀測值將落在 H < 0.3 區間 → multiplier 恆為 1.2 → 因子失去區分能力。這些閾值必須通過 walk-forward 穩定性測試，但當前完全沒有。
- **DFA 尺度選擇影響巨大**：`scales = [4, 8, 16, 32, 64]` 的選擇直接決定 H 估計值。尺度範圍太小（4–32）會低估長記憶、太高（4–128）需要更長視窗。不同尺度組合可能產生完全不同的 H 值。當前實作未做尺度穩健性分析。
- **兩層回歸放大估計誤差**：`_dfa_hurst` 先對每個尺度內的 N 個 segment 做線性回歸去趨勢，再對 log(F) vs log(s) 做 OLS 斜率估計。當 `window=100`、`scales=[4,8,16,32]`，每個尺度的 segment 數為 25、12、6、3，樣本極小。第二層 OLS 更只有 4 個點。兩層小樣本回歸的誤差傳播會使 H 的標準誤非常大。
- **Parkinson 估計器在 5-min 級別的適用性存疑**：Parkinson (1980) 是設計給日頻率資料的。在 5 分鐘級別，High-Low range 受 bid-ask bounce 和微結構雜訊的汙染程度遠高於日級別。這會使 Parkinson 波動率被高估，進而使 DFA 的 H 估計偏離真實粗糙度。
- **Multiplier 分段函數的邊界不連續性**：H 從 0.299 變為 0.301 時，multiplier 從 1.20 跳降至 1.00，這是 17% 的倉位突變。沒有平滑過渡（如 sigmoid），可能在邊界附近造成倉位振盪。
- **無 Permutation Test**：未對波動率序列進行隨機化（如 shuffle 或 phase randomization）後重新估計 H，無法確認觀測到的粗糙度信號超出隨機預期。

### 2. 經濟直覺穩健性

- **粗糙波動率 → 加倉的邏輯跳躍**：Gatheral 發現 H ≈ 0.1 意味著「波動率的變動是反持久的」——即波動率衝擊快速衰減。但這不直接推導出「此時應該加大倉位」。波動率衝擊衰減僅意味著波動率會回到均值，**不保證價格方向有利**。在 H < 0.3 時 multiplier=1.20，恰好是波動率較高的時期（因衝擊尚未完全衰減），等於在高波動時加倉 —— 這直接增加 tail risk，與 F3 宣稱的「降低 MDD 15-30%」目標自相矛盾。
- **行為學解釋缺乏實證**：「異質性反應速度導致粗糙度」是推測性敘述，未在任何引文中被實證檢驗。市場微結構中的粗糙度更可能來自訂單簿的離散性（tick size、lot size）和做市商庫存管理，而非交易者反應速度的異質性。
- **替代解釋：H 可能僅是波動率叢聚的簡單反映**。當市場經歷波動率飆升後回落，波動率序列呈現短暫的「反持久」外觀（因為均值回歸），DFA 會輸出低 H。但這僅是波動率叢聚+均值回歸的標準現象，與粗糙波動率理論的「跨時間尺度冪律衰減」有本質區別（後者要求自相似性跨越多個尺度）。
- **與波動率本身的共線性**：H < 0.3（加倉）發生在波動率衝擊後，此時 Parkinson vol 通常高於平均。multiplier=1.2 的「加倉」效果可能被同期的高波動率所抵消（若底層策略本身已有波動率調整）。F3 的增量資訊可能僅是高波動率的非線性變換，而非獨立的市場狀態維度。

### 3. 前視偏誤

- **代碼審查結果：無明顯前視偏誤**。`volatility_roughness_signal` 的滾動視窗僅使用 `park_vol[start:t+1]`（過往+當前）；`_parkinson_volatility` 每 K 線獨立計算；`_expanding_zscore` 使用 expanding window 僅含過往資料。✓
- **`_dfa_hurst` 內部無前視**：累積離差、去趨勢、log-log 回歸均在提供的視窗內完成，無外部資訊洩漏。✓
- **Minor concern**: `compute()` 中對 multiplier 做 `(multiplier - 1.0) / 0.2` 再 `_expanding_zscore`。由於 multiplier 是分段常數（僅取 0.5, 0.7, 1.0, 1.2 四個值），信號的 expanding z-score 初期非常不穩定——但這是標準化的固有限制，非前視偏誤。

### 4. 重複造輪子

- **與簡易 ATR 倉位管理的功能重疊**：SuperTrend 已有 `Vol≥1.1` 的波動率過濾器。一個更簡單的替代方案：當 ATR 或 Parkinson vol 高於近期均值時降低倉位，低於均值時恢復。這與 F3 的效果（波動率平穩→正常倉位，波動率異常→減倉）高度相似，但無需 DFA、Hurst、log-log 回歸等複雜計算。F3 的粗糙度維度是否帶來顯著增量有待實證。
- **與 F1 的互補性被高估**：筆記宣稱 F1+F3 正交且可組合，但兩者可能通過波動率共線。Δ（跨資產協同）在市場波動率飆升時傾向上升，而 H 在波動率飆升後傾向下降（反持久）。兩者對同一事件（波動率衝擊）的反應時間不同但資訊來源重疊。
- **與 super_trend_10_3 的相關性宣稱合理**（ρ < 0.15）：F3 不預測方向，僅調整倉位大小，與純方向性的 SuperTrend 確實正交。✓

### 5. 成本與流動性

- **低週轉率優勢**：作為倉位乘數，F3 本身不產生額外交易 —— 僅當 multiplier 變化時調整現有持倉規模。Hurst 估計視窗 = 100 期（500 分鐘 ≈ 8.3 小時），更新頻率低，週轉成本可控。這是三個因子中成本結構最友善的。✓
- **但 multiplier 的離散跳躍造成不必要調倉**：multiplier 僅取 {0.5, 0.7, 1.0, 1.2}，當 H 在閾值附近小幅波動時，multiplier 可能在 1.0 ↔ 1.2 或 0.7 ↔ 1.0 間反覆跳躍，產生無謂的倉位調整成本。建議改用連續函數（如 sigmoid）。
- **流動性無憂**：BTCUSDT 現貨市場深度充裕，倉位調整不會產生顯著市場衝擊。

## 與 F1 (Complexity_Gap_Regime) 的協同

這兩個因子從不同角度測量市場狀態：
- **F1 (Δ)**：測量跨資產的協同程度 (市場寬度)
- **F3 (H)**：測量單一資產波動率的時間序列特徵 (市場深度)

兩者正交且可組合：當 Δ 高 (有序) 且 H 低 (粗糙) 時 → 最強做多信號 (趨勢明確+波動率衝擊快速消退)；當 Δ 低 (無序) 且 H 高 (平滑) 時 → 最強避險信號。
