# F1: Complexity_Gap_Regime — 市場複雜度相位切換因子

## 因子類別
市場複雜度 / 體制切換 (Market Complexity / Regime Switching)

## 經濟直覺

金融市場並非始終處於同一狀態。透過隨機矩陣理論 (Random Matrix Theory, RMT) 分析資產收益率的相關矩陣，可以區分三種市場相位：

1. **無序相位 (Disordered Phase)**：Δ ≈ 0，相關矩陣的特徵值分佈接近 Wishart 隨機矩陣預測。市場參與者各自獨立交易，無統一方向 — 均值回歸主導。
2. **臨界相位 (Critical Phase)**：0 < Δ < 0.05，市場處於弱協同狀態。信號與雜訊邊界模糊 — 應收緊進場條件。
3. **有序相位 (Ordered Phase)**：Δ ≫ 0，存在一個顯著主導特徵值，表明市場參與者行為高度協同 (羊群效應) — 趨勢/動能主導。

**核心直覺**：Δ 度量的是市場從「隨機漫步」偏離的程度。當 Δ 極低時，價格變動缺乏方向性記憶，適合反轉策略；當 Δ 升高時，市場結構化程度增強，趨勢策略更有優勢。這不是預測價格方向，而是判斷當下最適合的策略類型。

## 與 super_trend_10_3 的差異

| 維度 | super_trend_10_3 | Complexity_Gap_Regime |
|------|------------------|----------------------|
| 核心邏輯 | 始終追隨趨勢 (動能+ADX) | 根據市場複雜度切換策略類型 |
| 對市場狀態的態度 | 不區分，只在方向明確時進場 | 主動識別相態並自適應切換 |
| 因子類型 | 純趨勢/動能 | 元因子 (meta-factor) / 策略選擇器 |

SuperTrend 永遠做多/做空趨勢，而 Complexity_Gap_Regime 在 Δ 低時建議均值回歸，Δ 高時建議趨勢 — 本質上是對 SuperTrend 的互補而非競爭。

## 計算方法草案

```
1. 取過去 N 根 K 線 (建議 N=60, 對應約 5 小時的 5-min 數據) 的標準化收益率矩陣 R (M 個資產 × N 個時間點)
2. 計算相關矩陣 C = (1/N) * R * R^T
3. 計算 C 的特徵值 λ_1 ≥ λ_2 ≥ ... ≥ λ_M
4. 標準化最大特徵值: λ_max_norm = λ_1 / sum(所有特徵值)
5. 計算複雜度間隙: Δ = λ_max_norm - ρ，其中 ρ = 1/M (均勻分佈基準)
6. 相位判定:
   - Δ < 0.02: 無序相位 → 均值回歸策略
   - 0.02 ≤ Δ < 0.05: 臨界相位 → 收緊進場條件 (僅做現有最強信號)
   - Δ ≥ 0.05: 有序相位 → 趨勢追隨策略
```

## 與既有論文洞見的對齊

- **直接對齊**：Complexity Gap Δ = λ_max_norm - ρ 三相位框架，Δ<0.05 收緊進場，假性恢復二次收窄觸發減倉
- **互補關係**：Cubic Momentum CMI 內建動量相變邏輯 — Complexity Gap 從完全不同的角度 (相關結構而非價格多項式) 達到相位識別
- **方法論支撐**：lead-time 度量要求 regime detection lead-time ≤ 0 (僅確認非預測) — RMT 方法基於協方差結構，可設計為純滯後確認

## 論文引用

- **Laloux, L., Cizeau, P., Bouchaud, J. P., & Potters, M. (1999).** "Noise Dressing of Financial Correlation Matrices." *Physical Review Letters*, 83(7), 1467. — 首次將 RMT 應用於金融相關矩陣，區分信號與雜訊特徵值。
- **Plerou, V., Gopikrishnan, P., Rosenow, B., Amaral, L. A. N., Guhr, T., & Stanley, H. E. (2002).** "Random Matrix Approach to Cross Correlations in Financial Data." *Physical Review E*, 65(6), 066126. — 實證檢驗不同市場狀態下特徵值結構的穩定性。
- **Bouchaud, J. P., & Potters, M. (2003).** *Theory of Financial Risk and Derivative Pricing*. Cambridge University Press. — Chapter 12 系統性討論 RMT 在投資組合風險和市場狀態分類中的應用。
- **Billio, M., Getmansky, M., Lo, A. W., & Pelizzon, L. (2012).** "Econometric Measures of Connectedness and Systemic Risk in the Finance and Insurance Sectors." *Journal of Financial Economics*, 104(3), 535-559. — 主成份分析與系統性風險連結，支持 Δ 作為市場協同度量。

## 預期特徵

- **IC 預期**：0.02–0.04 (作為元因子/策略切換器，本身不直接產生交易信號，而是修飾其他因子)
- **Sharpe 貢獻**：預期提升組合 Sharpe 0.1–0.3 (透過降低策略在不利市場狀態下的虧損)
- **與 SuperTrend 相關性**：預期 ρ < 0.3 (不同機制)
- **計算頻率**：建議每 5–15 分鐘重新估計 (N≥60 時有足夠統計穩定性)

## 風險與限制

1. **特徵值估計不穩定性**：N=60 對 M 個資產的協方差矩陣估計可能不足。需使用 shrinkage estimator (Ledoit-Wolf) 提高穩健性。
2. **資產選擇敏感度**：Δ 值依賴於資產池的組成。若資產過於同質 (如同一行業)，Δ 會被高估。
3. **滯後性**：基於歷史協方差結構的 Δ 本質上是滯後指標，在快速制度轉換時可能有延遲。

## 質疑（五維批判）

### 1. 資料探勘風險

- **參數任意性嚴重**：`window=60`、`n_components=10`、相位閾值 `[0.02, 0.05]` 三者均無嚴謹推導。筆記中稱「建議 N=60」但未提供任何最佳化依據（如 walk-forward 驗證、敏感度分析）。`n_components=10`（虛擬資產數）更是憑空選擇 —— 為什麼不是 8 或 12？不同 `n_components` 會顯著改變 Δ 的分布範圍。
- **信號映射公式為事後捏合**：`signal = clip((Δ - 0.035) / 0.04, -1, 1)` 中的 0.035 和 0.04 完全是 heuristics，沒有理論支持，也沒有從資料中穩健估計。這兩個魔術數字直接決定了信號的激活閾值與敏感度。
- **收縮強度公式未校準**：`shrinkage_intensity = min(0.3, n_components / (window * 2))` ≈ 0.083，既不是 Ledoit-Wolf 最優收縮，也不是基於任何交叉驗證。僅是防止矩陣奇異的應急措施。
- **單品種適配為方法論跳躍**：原始 RMT（Laloux 1999, Plerou 2002）是對 **M 個資產 × N 個時間點** 的跨資產相關矩陣做特徵值分解，量化的是市場寬度的協同程度。本實作將其改為 **單一資產的子區段自相關矩陣**，物理含義已發生質變 —— 測量的是「價格自相似性」而非「跨資產協同」。沒有任何論文支持此轉換的有效性。
- **缺乏 Permutation Test**：完全沒有對 Δ 序列進行隨機化檢驗（如 shuffle 價格後重新計算 Δ 分布），無法排除 Δ 僅是隨機波動的可能性。

### 2. 經濟直覺穩健性

- **相位-策略映射缺乏因果鏈**：「Δ 低 → 均值回歸、Δ 高 → 趨勢」這條推理鏈沒有直接文獻支持。RMT 論文僅區分「信號特徵值」與「雜訊特徵值」，並未論證低 Δ 時均值回歸策略更優。低 Δ 完全可能對應低波動率的緩慢單邊市場（均值回歸策略在此反而虧損）。
- **替代解釋未被排除**：Δ 可能僅是市場波動率的代理變量（高波動時期跨資產相關性上升是已知的 stylized fact）。若 Δ ∝ VIX-like，則 F1 並未提供超出簡單波動率過濾器的增量資訊。
- **自相關矩陣的物理意義存疑**：單品種子區段自相關矩陣的最大特徵值，本質上捕捉的是「收益率序列在多大程度上可由單一主成分解釋」——即趨勢性的強度。若價格隨機漫步，各子區段不相關，Δ ≈ 0；若價格強趨勢，子區段高度相關，Δ ≫ 0。這只是一個**趨勢強度指標**，並未真正區分「均值回歸適合區間」與「趨勢適合區間」。
- **因果混淆風險**：Δ 在有序相位時給出正信號（做多），但此時價格可能已在高位（上漲趨勢尾端）。若市場隨後轉向，F1 將在最差的時點建議趨勢策略。

### 3. 前視偏誤

- **代碼審查結果：無明顯前視偏誤**。`complexity_gap_signal` 的滾動視窗僅使用 `[t-window+1, t]`；`_expanding_zscore` 使用 expanding window 僅含過往資料；`_safe_log_returns` 的缺失值填補僅使用前值。✓
- **細微問題**：`_form_lagged_correlation_matrix` 中 `sub_len = n - n_components + 1`，當 `n=60, n_components=10` 時 `sub_len=51`，即每個子區段 51 個收益率觀測值。51 個觀測值估計 10×10 相關矩陣（45 個獨立參數），觀測值/參數比 ≈ 1.13，極度不足，估計結果高度不穩定。

### 4. 重複造輪子

- **與 super_trend_10_3 的宣稱差異 vs 實際重疊**：筆記宣稱 F1 為「元因子 / 策略選擇器」，但實作輸出的是可直接交易的 [-1, 1] 信號。在有序相位（Δ ≥ 0.05），F1 輸出正信號 → 等效於做多趨勢；而 SuperTrend 也做多趨勢 → 此時兩者高度正相關。僅在無序相位時兩者方向可能相反。總體相關性可能顯著高於宣稱的 ρ < 0.3。
- **本質上是一個趨勢強度探測器**：如前所述，子區段自相關矩陣的最大特徵值實質上就是測量趨勢強度。這與傳統動量因子（如過去 N 期累積收益）捕捉的資訊高度重疊。
- **未與既有因子庫正式比對**：筆記僅比較了 SuperTrend，未與任何其他常見因子（動量、反轉、波動率）進行相關性分析。

### 5. 成本與流動性

- **週轉率隱憂**：建議計算頻率 5–15 分鐘。若每 15 分鐘重新計算並可能觸發調倉，每日可達 96 次信號更新。以 crypto 0.09%/side 計算，來回交易成本 0.18%，若每日換手超過 5 次即年化成本超過 200%。筆記完全未討論週轉率與成本侵蝕。
- **相位切換的雙重成本**：當 Δ 從無序切換至有序，信號從負翻正 → 需要從空頭翻多頭，產生額外交易成本。相位邊界附近的頻繁振盪可能急劇推高成本。
- **流動性尚可**：BTCUSDT 流動性充裕，中小資金不構成瓶頸，但大資金在 5 分鐘級別上可能有滑點。
