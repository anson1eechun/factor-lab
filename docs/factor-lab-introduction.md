# Factor-Lab：Multi-Agent 量化因子研究自動化系統

## 一句話

**一個能自己爬論文、自己辯論因子好壞、自己回測驗證、自己產報表的 AI 因子研究員** — 你只需要每天早上打開儀表板看結果。

---

## 這系統在做什麼

傳統量化因子研究是這樣：研究員讀論文 → 想到一個因子 → 寫程式實作 → 跑回測 → 看結果 → 淘汰或保留。一個因子從構想到驗證，熟練的研究員也要 1-3 天。

Factor-Lab 把這個流程全自動化了。它有三層運作：

### 第一層：每天自動讀論文

每天早上 8 點和晚上 8 點，系統自動掃描：
- **arXiv**：最新量化金融論文（q-fin 分類）
- **專業部落格**：Quantpedia、Robot Wealth 等量化研究網站
- **Threads**：量化交易實戰作者的策略分享（目前追蹤 @voltima_quant）
- **Glassnode**：鏈上數據圖表，透過 Gemini Vision 轉成文字摘要

所有內容自動歸檔到兩個地方：
- **Obsidian 知識庫**：人類可讀、可搜尋、可連結的筆記
- **index.db**（SQLite）：結構化資料，供辯論管線查詢

### 第二層：每週自動辯論新因子

週日凌晨 3:00（你睡覺的時候），6 個 AI agent 輪番上陣：

| 步驟 | 角色 | 模型 | 工作 |
|------|------|------|------|
| ① | Proposer | Claude Sonnet 4.6 | 讀取本週所有論文，提出 2-3 個有經濟直覺的因子假設 |
| ② | Builder | Claude Sonnet 4.6 | 把假設寫成 Python 信號函數，跑 smoke test 確認沒 bug |
| ③ | Skeptic | Claude Sonnet 4.6 | 從五個維度質疑：資料探勘？經濟直覺？前視偏誤？重複造輪子？流動性？ |
| ④ | Empiricist | Claude Sonnet 4.6 | 用歷史數據回測，產出 Rank-IC、IC-IR、分組回報 |
| ⑤ | Arbiter | DeepSeek V4 Pro | 讀取前面所有人的分析，做出 PASS / CONDITIONAL / REJECT 裁決 |
| ⑥ | Librarian | DeepSeek V4 Flash | 把通過的因子歸入因子庫，淘汰的歸入棄用區，更新資料庫 |

整個辯論過程逐字記錄在 `debate_transcripts` 表中 — 你隨時可以回顧某個因子為什麼被淘汰。

### 第三層：自動回測 + 儀表板

- **週三凌晨**：系統對所有已通過驗證的因子重新跑一次回測（因為每天都有新行情），更新報表
- **每天凌晨**：刷新 Mission Control 儀表板，確保你早上打開看到的是最新數據

## 技術棧

- **語言**：Python 3.14
- **資料處理**：Polars、NumPy、Pandas
- **回測引擎**：AlphaPurify（PBO / Purged CV / Walk-Forward）
- **視覺化**：Plotly（互動報表）、自訂 HTML/CSS（儀表板）
- **資料庫**：SQLite（因子註冊表、實證記錄、辯論逐字稿）
- **知識庫**：Obsidian（Markdown + wikilinks + YAML frontmatter）
- **排程調度**：Hermes Agent CLI（cron job 管理 + multi-agent 調度）
- **爬取**：Scrapling + Playwright（Threads）、CCXT（行情）、arXiv API
